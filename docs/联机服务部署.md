# 联机服务部署

联机服务（`packages/server`）跑在 `goblin.top` 的 Docker 里，客户端连接 `wss://5ele.goblin.top/ws`。

| 项 | 位置 |
|---|---|
| 代码 | 服务器 `/opt/5ele`（从本仓库 rsync 过去，不含 client） |
| 容器 | `5ele-server`，只监听 `127.0.0.1:2567` |
| 存档 | Docker 卷 `5ele_5ele-data`，容器内 `/data/players/<设备号>.json` |
| 反代 | `/etc/nginx/sites-available/5ele.goblin.top`，证书由 certbot 管理 |
| 健康检查 | `https://5ele.goblin.top/health` |

## 更新服务端

```bash
rsync -az --delete -e "ssh -p8022" \
  --exclude node_modules --exclude dist --exclude /.git --exclude /packages/client --exclude /data \
  ./ root@goblin.top:/opt/5ele/
ssh -p8022 root@goblin.top 'cd /opt/5ele && docker compose up -d --build'
```

容器收到停止信号时会先把存档写盘再退出。

## 本地开发

```bash
pnpm --filter @xiyou/shared build
pnpm --filter @xiyou/server dev     # ws://localhost:2567
pnpm --filter @xiyou/client dev     # 开发模式自动连本机 2567
```

客户端可用 `VITE_SERVER_URL` 指定其他服务器地址。
