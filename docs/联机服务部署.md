# 联机服务部署

联机服务（`packages/server`）跑在 `goblin.top` 的 Docker 里，客户端连接 `wss://5ele.goblin.top/ws`。

| 项 | 位置 |
|---|---|
| 代码 | 服务器 `/opt/5ele`（从本仓库 rsync 过去，不含 client） |
| 容器 | `5ele-server`，只监听 `127.0.0.1:2567` |
| 存档 | Docker 卷 `5ele_5ele-data`，容器内 `/data/players/<设备号>.json` |
| 反代 | `/etc/nginx/sites-available/5ele.goblin.top`，证书由 certbot 管理 |
| 健康检查 | `https://5ele.goblin.top/health` |

## 更新服务端

```bash
rsync -az --delete -e "ssh -p8022" \
  --exclude node_modules --exclude dist --exclude /.git --exclude /packages/client --exclude /data --exclude /model \
  ./ root@goblin.top:/opt/5ele/
ssh -p8022 root@goblin.top 'cd /opt/5ele && docker compose up -d --build'
```

容器收到停止信号时会先把存档写盘再退出。

## 本地开发

```bash
pnpm --filter @xiyou/shared build
pnpm --filter @xiyou/server dev     # ws://localhost:2567
pnpm --filter @xiyou/client dev     # 开发模式自动连本机 2567
```

客户端可用 `VITE_SERVER_URL` 指定其他服务器地址。

## 存档与备份

- 存档在 Docker 数据卷 `5ele_5ele-data` 的 `players/` 里，每个玩家一个 JSON。
- 没有账号密码：浏览器里存一个设备标识，服务器按它找存档。每份存档另有一串 12 位的**存档码**（营地右上角「存档码」），换设备时输入它就能接回；它等同于密码。
- **每天自动备份**：服务器上的 cron（`/etc/cron.d/5ele-backup`）每天 04:17 跑 `deploy/backup.sh`，打包到 `/root/5ele-backups/5ele-daily-<日期>.tgz`，保留 30 天，日志在 `/var/log/5ele-backup.log`。
- 部署前另外手动打一份到 `/root/5ele-backup-<时间>.tgz`。
- 恢复：停服务 → 把某个备份解到数据卷里 → 起服务：

```bash
ssh -p8022 root@goblin.top
cd /opt/5ele && docker compose stop
docker run --rm -v 5ele_5ele-data:/data -v /root/5ele-backups:/backup alpine \
  sh -c 'rm -rf /data/* && tar xzf /backup/5ele-daily-<日期>.tgz -C /data'
docker compose up -d
```
